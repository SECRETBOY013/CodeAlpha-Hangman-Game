
# Hangman Game - Python

## Project Description
Hangman is a simple word-guessing game developed using Python.
The player tries to guess a hidden word one letter at a time.

## Features
- Random word selection
- Six incorrect attempts allowed
- Input validation
- Duplicate guess detection
- Win and lose messages
- Option to play again

## Technologies Used
- Python 3
- Random module

## How to Run
1. Install Python 3.
2. Download or clone this project.
3. Open a terminal in the project folder.
4. Run the following command:

   python hangman.py

## How to Play
- Enter one alphabet at a time.
- Correct guesses reveal letters.
- Incorrect guesses reduce the remaining attempts.
- Guess the full word before attempts run out to win.
